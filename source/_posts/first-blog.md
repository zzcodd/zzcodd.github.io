这是我的第一篇博客。

我想找一个地方，保存学到的知识、做过的小实验，以及生活里值得记住的事情。第一版的目标很简单：**把一篇文章写出来，让它能在网页上被读到。**

## 一篇文章，是怎么变成网页的？

这篇文章的原稿是一份 Markdown 文件。Hexo 读取正文、标题、日期和标签，Butterfly 则为它提供布局、字体、导航和侧栏。

整个过程可以这样理解：

> 写文章 → 本地预览 → 生成网页 → 发布网站

我日常需要维护的，主要是文章本身，以及少量站点和主题配置。

## 写作只需要一个 Markdown 文件

比如，给文章添加小标题、列表和代码块：

- **小标题**让长文更好读。
- **标签和分类**方便以后整理。
- **代码块**适合记录可以再次运行的小例子。

```javascript
const firstPost = {
  title: '我的第一篇博客',
  status: '开始记录'
};

console.log(firstPost.title);
```

这些都是普通的 Markdown 内容，不需要为每一篇文章单独编写网页。

## 下一篇，写什么？

可以是一份解决问题的笔记，也可以是最近读完的一本书。每次只写清楚一件事，就足够了。

第一篇文章的意义，是让下一篇更容易开始。
